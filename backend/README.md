# RightTimeMD Backend

Node.js + Express + TypeScript backend for the RightTimeMD FHIR healthcare platform.

## Features

- 🏥 **FHIR Resource Management**: Create, read, update, delete FHIR resources
- 🔒 **Supabase Integration**: Direct database connection with RLS security
- 📊 **Patient Data Access**: Secure provider access to patient FHIR data
- 🎯 **Type Safety**: Full TypeScript coverage with FHIR types
- ⚡ **Performance**: Optimized queries with pagination support

## Security

- **Row Level Security**: All data access controlled by Supabase RLS
- **HIPAA Compliance**: Audit logging and consent management
- **Type Validation**: Zod schemas for environment and API validation
- **Error Handling**: Comprehensive error handling with security in mind
